# Setup — what to connect and why

Read this when the user asks to set up intake-prep, asks what they should connect, or when the capability check at PREP finds a high-value tool missing. The skill works with nothing connected; each connection below makes a specific part of the output sharper. Present these as recommendations ranked by impact, ask which they want to connect, and point them to where connections live in the Claude app (Settings → Connectors, or the Claude in Chrome extension for the browser). Menu names vary slightly by version; describe the destination, let them find the path.

## Ranked by impact on intake quality

**1. Browser with a logged-in LinkedIn session (Claude in Chrome).**
The single biggest upgrade. Powers the calibration sourcing run: 6–8 real, verified candidate profiles the hiring manager reacts to live on the call, plus team mapping inside the client. Without it, calibration falls back to labelled archetypes, which extract far fewer decisions from the call.
*Pitch when missing:* "Connect Claude in Chrome and log into LinkedIn, and I can source real calibration profiles instead of archetypes. It's the difference between the client reacting to real people and reacting to sketches."

**2. Email and calendar.**
Finds the client thread, the meeting slot, the attendees, and the meeting length. A 30-minute slot changes which questions survive; knowing who is in the room changes the persona plan.
*Pitch when missing:* "With calendar and email connected I can confirm the meeting length and who's in the room, and prioritise the question set to fit. For now, tell me: how long is the call and who's attending?"

**3. Internal documentation (Notion, Drive, or wherever account notes live).**
Repeat-client context: prior roles, past intakes, known do-not-contact lists, what the client already told us. Internal beats web; one line from a client profile settles what an hour of research would guess at.
*Pitch when missing:* "If your account docs live in Notion or Drive, connecting them means I start from what we already know about this client instead of rediscovering it."

**4. Transcript source (Fireflies, or wherever call recordings land).**
Makes LOG one step: "log the [client] intake" pulls the transcript directly. Without it, drop the transcript PDF into the chat, which works fine.

**5. People-data connectors (Apollo, Clay, ZoomInfo), where the recruiter has a licence.**
Company-targeted candidate discovery at scale and org mapping. A supplement to the browser route, never a requirement.

## How to run the nudge during PREP

- One short block, once per session, at the capability check: name the missing tool with the highest impact, give its one-line pitch, then continue with what is available. Never stall the prep on it.
- If the user wants to connect something, point them to Settings → Connectors (or the Chrome extension) and offer to pick up the prep again after.
- If two or more high-impact tools are missing, mention the top one and add: "ask me to set up intake-prep when you have ten minutes and I'll walk you through the rest."
- Once a tool is connected, use it silently; the nudge retires itself.

## The full setup walk-through (on request)

When asked to set up intake-prep, go through the ranked list above one at a time: what it adds, whether they have access to that tool at their account, and how to connect it. Some connectors need authorisation the recruiter's account may lack (client systems especially); where access is the blocker, note what the tool would have added and move on. Close by running a dry PREP on a live role so they see the output shape immediately.
